First launch

Heracles Records is not yet signed with an Apple or Microsoft developer certificate, so your system asks once before it opens the app.

macOS

  1. Open the .dmg and drag Heracles Records into Applications.
  2. If macOS says it cannot check the app, open System Settings → Privacy & Security and click Open Anyway.
  3. If it says the app is damaged, run this in Terminal, then open the app again: 
    xattr -dr com.apple.quarantine "/Applications/Heracles Records.app"

Windows

Run the installer. If SmartScreen warns about an unrecognised app, click More info → Run anyway.

Linux

For the AppImage, make the file executable and run it:

chmod +x HeraclesRecords-*.AppImage
./HeraclesRecords-*.AppImage

For the deb, install it with apt, then open Heracles Records from the app menu. Updates ask for your password, as any system package does. 

sudo apt install ./HeraclesRecords-*.deb

Check a download

Each installer's SHA-256 is listed above, as GitHub computed it when the release was published. To compare it with the file you downloaded: 

# macOS and Linux
shasum -a 256 HeraclesRecords-*

# Windows (PowerShell)
Get-FileHash .\HeraclesRecords-Setup-*.exe -Algorithm SHA256

What you need

  • A COROS account. Any COROS watch that syncs to it will do.
  • For Coach, an AI (optional): your ChatGPT account, a Claude subscription, a Claude or OpenRouter API key, or a model running on your own computer. See Set up Coach.
  • For sleep and health data, the COROS MCP connection, made from inside the app in a minute. See Sleep and health data.

Updates

The app checks GitHub for a new version and tells you when one is out. You can also check by hand under Settings → About.
